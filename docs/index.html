Windows 窗口防误关工具

KeepWindow 可以禁用标准关闭命令，或用鼠标遮罩保护自绘标题栏的关闭按钮。

机制

系统关闭保护

禁用目标窗口系统菜单中的关闭项，原生适配标准 Windows 标题栏。

鼠标遮罩

覆盖自绘标题栏的关闭按钮，支持 DPI 缩放、窗口移动、调整大小与坐标校准。

规则与恢复

按程序与窗口特征自动挂载保护；异常退出后，安全恢复匹配窗口的原始状态。

UI

使用

解压并运行 keep-window.exe
